Stack y Arquitecturas de Software

Aplicación web con un cuestionario interactivo sobre los conceptos trabajados en clase: arquitectura hexagonal, Clean Architecture, arquitecturas orientadas a eventos, monolito modular, stack tecnológico y flujo de trabajo con Git, GitHub y Render.

Stack tecnológico

  • Lenguaje: Python
  • Backend: Flask
  • Frontend: HTML, CSS y JavaScript
  • Versionado: Git y GitHub
  • Despliegue: Render

Arquitectura

Monolito modular organizado según el patrón MVC. El modelo contiene los datos del quiz, el controlador valida las respuestas y la vista presenta la interfaz.

Funcionalidad

  • preguntas con cuatro opciones cada una.
  • Identificación de la opción seleccionada.
  • Retroalimentación inmediata y explicada.
  • Puntuación final con opción de reintentar.
